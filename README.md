# ColorLab MVP

Статическое приложение для генерации цветовых палитр, предпросмотра UI-компонентов и экспорта дизайн-токенов.

## Возможности
- HEX-палитра из пяти оттенков и копирование цветов
- Светлая и тёмная темы, выбор шрифта и радиуса
- Предпросмотр компонентов
- Экспорт CSS-переменных и JSON
- Локальное сохранение настроек в localStorage

## Запуск
Откройте `index.html` в браузере. Для Clipboard API рекомендуется HTTPS.

## GitHub Pages
В Settings → Pages выберите Deploy from a branch → `main` → `/ (root)` и сохраните. Адрес публикации: https://maksappgames-cyber.github.io/colorlab/

База данных, платные API, домен и отдельный хостинг не требуются. Настройки хранятся в браузере и не синхронизируются между устройствами.
